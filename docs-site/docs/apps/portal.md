# Portal

One Next.js app, two audiences: an open-data portal for downstream API
consumers, and the operational back office (fleet, routes, drivers, duty
assignment, live dispatch) for agency staff. Role-gated per the agency-scoped
RBAC model described in [ADR 0003](../wiki/adr/0003-custom-access-token-hook.md).
