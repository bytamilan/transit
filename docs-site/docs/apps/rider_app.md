# Rider App

Live vehicle map, nearby-stop arrivals, route shapes, a multimodal trip
planner, GO turn-by-turn navigation, rider profile, digital transit pass, and
an offline timetable fallback. Built with Flutter, targeting iOS, Android, and
web from a single codebase.

## Inspired Design System

Inspired by Transit iOS with full-bleed color-coded route lines, large countdown
arrival pills, interactive multimodal routing, and crowdsourced GO companion mode.
